# AI Event Team Formation System

An AI-based project that automatically forms event teams using Constraint Satisfaction Problems (CSP) and the Backtracking algorithm.

## Features
- Register students with their skills.
- Track student availability.
- Generate teams automatically.
- Check required skills and team constraints.
- Display an explanation of the CSP model.

## Technologies Used
- Python
- Tkinter GUI
- Constraint Satisfaction Problem (CSP)
- Backtracking Algorithm

## Project Files
- `main.py` — Graphical user interface.
- `csp_solver.py` — Team formation logic.

## How to Run
1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command:

```bash
python main.py
```

## Project Objective
To simplify event team formation by assigning available students to teams while satisfying required skill constraints.
